# 🌍 가상국가 전쟁 시뮬레이션

**가상국가전쟁시뮬레이션.md** 스펙을 기반으로 만든, **서버 없이 브라우저에서만 작동하는** 가상국가 전쟁 시뮬레이션입니다.

- 9×6 육각(hex) 지도 위의 7개 가상 국가 + 플레이어가 직접 창건하는 국가
- 국가들은 스스로 경제·군사·외교·정치를 결정하며, 플레이어는 그 세계에 개입합니다
- **GitHub Pages에 무료로 배포** 가능한 순수 정적 사이트 (HTML/CSS/JS + SVG)

## 주요 기능

| 영역 | 내용 |
|---|---|
| 세계 | 9×6 hex 지도(54 지역), 7개 프리셋 국가, 4개 무인 창건지, 자동 뉴스/시대(평화·국지전·세계대전) |
| 게임 루프 | AI 국가가 매 턴 예산/외교/침략/전쟁 종결을 자율 판단, 날짜 1일씩 진행 |
| 경제 | GDP·세율·국고·부채·물가·실업, 예산 5개 항목 슬라이더, 투자/복지, 무역협정, 제재 |
| 군사 | 병력/예비군/해군/공군/장비/기술/사기/동원, 모병/훈련/장비구매, 침략 선포(6종 명분), 전선·점령·피로도 |
| 외교 | 관계도(±100), 동맹(상호방위), 무역협정, 지원(공개/비밀), 제재, 사절 |
| 정보 | 정보 작전으로 타국의 군사·경제 정보를 신뢰도에 따라 대략적으로 표시 |
| 정치 | 지지도/안정도/파벌/쿠데타 위험, 개혁·숙청·비상사태 등 대응 |
| 전쟁 | 명분 별 국내 지지/국제 반감, 진격 게이트에 따른 점령, 동맹 참전, 사상자/피로, 휴전·항복(할양)·배상금 |
| 저장 | 자동 저장(localStorage) + JSON 파일 내보내기/불러오기 |

## 실행 방법

### 1) 로컬에서 실행
```bash
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속. (파일을 직접 열어도 동작하지만, 브라우저 정책에 따라 localStorage가 안 될 수 있으므로 서버 권장)

### 2) GitHub Pages에 배포
이 프로젝트는 순수 정적 파일만으로 구성되어 있어 **추가 설정 없이** GitHub Pages로 게시할 수 있습니다.

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 푸시합니다.
   ```bash
   git init
   git add .
   git commit -m "가상국가 전쟁 시뮬레이션"
   git branch -M main
   git remote add origin https://github.com/<사용자명>/<저장소명>.git
   git push -u origin main
   ```
2. 저장소 페이지 → **Settings → Pages** 클릭
3. **Build and deployment** → Source를 **Deploy from a branch**로 선택
4. Branch를 `main` + 루트`/`로 지정하고 **Save**
5. 1~2분 후 `https://<사용자명>.github.io/<저장소명>/` 에서 플레이 가능

> 참고: 게임 진행 데이터는 브라우저 **localStorage**에 저장되므로, 저장소/배포 방식과 무관하게 기기별로 관리됩니다.

## 컨트롤

- 새 게임: 국가 이름·수도·지도자·정부·색상·성향을 정하고, 지도에서 **노란색 무인 지역**을 클릭해 창건
- 지도 클릭: 아군 영토 = 내 국가 패널, 적군 영토 = 국가 정보 모달, 무인 지역 = 편입 모달
- 하단 버튼: ⏩ 턴 종료 / 💾 저장(JSON 다운로드) / 📂 불러오기 / 🎮 새 게임
- 탭: 국가 / 경제 / 군사 / 외교 / 정보 / 정치 / 세계 / 뉴스

## 프로젝트 구조

```
.
├── index.html          # 진입점 (지도 + 패널 + 탭 + 뉴스)
├── style.css           # 반응형 다크 테마
├── app.js              # 앱 부팅 + 전역 오류 표시
└── js/
    ├── data.js         # 지도(hex)/국가 7개/명분/이벤트 정적 데이터
    ├── country.js      # 국가 객체 (경제·군사·사회·외교·직렬화)
    ├── world.js        # 시뮬레이션 엔진 (턴 루프·전쟁·AI·뉴스·직렬화)
    ├── save.js         # localStorage 자동저장 + JSON 파일
    └── ui.js           # 화면 렌더링 + 플레이어 조작 (XSS 이스케이프 포함)
```

## 기술 메모

- 외부 의존성(CDN/라이브러리) 없음, 순수 ES5 스타일 → 모든 현대 브라우저 호환
- 사용자 입력(국가명/지도자/수도 등)은 `esc()`로 **HTML 이스케이프** 처리
- 세이브 파일은 `v:1` 포맷 검증 후 복원
- 스모크 테스트(헤드리스 Chrome): 401턴 시뮬레이션, 전쟁/외교/세이브 무결성, NaN-프리 확인 완료
